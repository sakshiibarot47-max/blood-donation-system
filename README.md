# Blood Donor Management System

A Java web application developed in Eclipse for connecting blood donors with seekers in real time.

## 🚀 Features
* **User Authentication:** Login and Logout functionality (`LoginServlet`, `LogoutServlet`).
* **Donor Registration:** Register as a blood donor (`RegisterDonorServlet`).
* **Search System:** Search for available donors by blood group or city (`SearchByBloodGroupServlet`, `SearchByCityServlet`).
* **Emergency & Request Tracking:** Place emergency blood requests and track request history (`EmergencyRequestServlet`, `RequestHistoryServlet`).

## 🛠️ Tech Stack
* **Backend:** Java (Servlets)
* **Frontend:** JSP, HTML, CSS
* **Database:** MySQL
* **IDE:** Eclipse IDE for Enterprise Java / Web Developers
* **Server:** Apache Tomcat
